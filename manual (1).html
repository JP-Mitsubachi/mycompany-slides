自動投稿の仕組み

12:00・20:00に自動で投稿されるしくみ

むずかしい話は読まなくていいですが、「なんで自動で投稿されるの？」が気になる方向けに説明します。

1

承認後、キューファイルに保存される

「OK」を出すと、2本目・3本目のツイートが以下のファイルに保存されます：

x-bot/data/queue.json
📦 「キュー」は「待ち行列」のこと。投稿待ちのツイートが入る箱です。
2

macOSのタイマーが起動する

パソコンには「LaunchAgent（ランチエージェント）」という時計係がいます。毎日12:00と20:00になると自動で起動します。

🕐 → 12:00になった！
🤖 → queue.jsonを開く
📤 → 2本目をXのAPIで投稿
📝 → post-log.mdに記録
🗑️ → キューから削除
3

ログで結果を確認できる

投稿した結果は以下のファイルに記録されます：

x-bot/logs/scheduled.log
✅ 投稿が成功すると「✅ 投稿成功 → https://x.com/h_shunosuke/status/...」と記録されます。

ファイルの見方

どこに何があるかを把握しておこう

x-bot/
├── drafts/ ← 毎日のドラフト（YYYY-MM-DD-draft.md）
├── data/
│ ├── queue.json ← 投稿待ちツイート（承認後に保存される）
│ └── used_articles.json ← 使用済み記事（重複防止）
├── logs/
│ ├── post.log ← 1本目の投稿ログ
│ └── scheduled.log ← 2・3本目の投稿ログ
├── post.py ← 即時投稿スクリプト（触らなくてOK）
└── queue_post.py ← キュー投稿スクリプト（触らなくてOK）

.company/marketing/X運用/team/data/
├── post-log.md ← 全投稿の記録（分析の元データ）
├── weekly-review.md ← 週次PDCA
└── scout-list.md ← 交流アカウントリスト
⚠️ py ファイルや json ファイルは直接編集しないでください。 Claudeが自動で管理します。

よくある質問

困ったときはここを見てください

12:00になっても投稿されない
▼
① パソコンがスリープ中だと動きません。12:00前にスリープを解除しておいてください。

② x-bot/data/queue.json を開いて、今日の日付のデータが入っているか確認してください。空の場合は承認が完了していません。

③ それでもダメなら Claude Code で「12時の投稿を手動で実行して」と伝えてください。
ドラフトが気に入らない場合はどうする？
▼
「2本目を〇〇というテーマに変えて」と言えば書き直してくれます。何度でも修正OKです。

また、.company/marketing/X運用/strategy.md の「テーマ」や「トーン」を書き換えると、次回からの方向性が変わります。
Coworkから操作するときと Claude Code から操作するときの違いは？
▼
Cowork（デスクトップアプリ）： ドラフト生成・修正・承認・queue保存まで可能。ただし1本目の即時投稿はできません。

Claude Code（ターミナル）： すべての操作が可能。承認後に1本目をその場でXに投稿できます。

朝の操作はできればClaude Codeで行うのがおすすめです。
投稿したツイートを確認する方法は？
▼
① X（Twitter）のプロフィールページ @h_shunosuke を開く。
② または x-bot/logs/post.log や x-bot/logs/scheduled.log を開くと、投稿されたURLが記録されています。
今日の投稿をキャンセルしたい
▼
Claude Code に「今日の2本目・3本目の投稿をキャンセルして」と伝えてください。queue.json からエントリを削除します。

すでに投稿済みの場合はXから手動で削除してください。
週次レビューはいつやるの？
▼
月曜日の朝がおすすめです。先週のデータをもとに今週のドラフト方針を最適化できます。
必須ではありませんが、続けると投稿の精度が上がります。

困ったらしゅうさんに聞いてください
