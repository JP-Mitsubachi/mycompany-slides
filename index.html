02 / 10
Concept

このキットが解決すること

🧠
記憶が続かない問題
タスク・日記・会議録・アイデアをすべてMarkdownファイルに永続化。Claude が毎回「どこ？」と迷わない。
🔀
何でも屋になってしまう問題
7つの部署に役割を分けて委任。秘書・PM・開発を「別人格」として使い分けられる。
⚡
毎回セットアップが面倒な問題
CLAUDE.md にルールを集約。新しい会話でもコンテキストが即復活する。
🔌
専門タスクに対応できない問題
必要なスキルを後からインストールして拡張できる。自分だけの組織に育てられる。

Setup

セットアップ手順（5分）

1
リポジトリをクローン
git clone https://github.com/YOUR_REPO/teru-company-starter.git mycompany
2
Claude Code を起動
プロジェクトフォルダで claude を実行。または VS Code の Claude Code 拡張から開く。
3
オーナープロフィールを設定
.company/CLAUDE.md を開き、「事業・活動」「目標・課題」を書き換える。これだけで完了。
4
日本語で話しかける
「タスク追加 〇〇」「アイデア 〇〇」「MTG 〇〇」と送るだけで動き始める。

08 / 10
Maintenance

運用・保守のしかた

🔄 日次メンテナンス
「今日のタスク」で秘書室の状態確認
完了タスクはチェック→秘書が自動アーカイブ
メモ・アイデアは inbox に投げるだけでOK
📅 週次メンテナンス
「週次レビュー」で1週間の成果を振り返る
pixel-office の update_data.py を実行して稼働状況を更新
古い inbox のメモを各部署に仕分け
🔌 スキルの追加・更新
/find-skills でスキルを検索・インストール
古いスキルは .agents/skills/ から手動削除
部署追加は .company/新部署/CLAUDE.md を置くだけ
🛡️ セキュリティ
APIキー・パスワードは絶対にファイルに書かない
環境変数 or .env（.gitignoreに追加済み）を使う
/security-review でコードを定期監査
