当社のSEO業務は Claude（AI） が自動でやってくれます。

むずかしいことは何もありません。一緒にやってみましょう！

記事を投稿する

新しいSEO記事をサイトに公開する方法

1

Claude Code を開く

パソコンで Claude Code（ターミナルの中にあるAI） を起動します。

💡 Claude Code は黒い画面（ターミナル）の中で動きます。わからない場合はしゅうさんに聞いてください。
2

SEOフォルダを開く

Claude Code で以下のフォルダを開きます：

~/Desktop/shu-company/IBT-SEO-Team
💡 ターミナルに cd ~/Desktop/shu-company/IBT-SEO-Team と入力してEnterを押す
3

Claudeに「投稿して」と伝える

Claude に向かって、次のように話しかけます：

記事を投稿して

または

今日の記事を投稿して
4

完了を待つ（約5〜10分）

Claudeが自動で記事を書いて、サイトに公開してくれます。

✅
こんな表示が出たら成功です：

✅ 投稿完了 (post_id=○○○)
🔗 https://ib-tec.co.jp/career-advice/○○○/

URLをクリックして記事を確認しましょう！
📈

SEO順位を確認する

Googleで何位に表示されているかを調べる方法

1

KeywordMapにアクセスする

ブラウザで下記URLを開きます：

🔒 keywordmap.jp/login
KeywordMap は、Googleの検索順位を一覧で見られるツールです。
毎日自動で順位を計測してくれます。
🔗 KeywordMapを開く →
2

ログインする

以下のID・パスワードを入力してログインします：

🔑 ログイン情報
ログインID
otokake0715
パスワード
Otokake0715!
⚠️ このID・パスワードは社外秘です。社外の人に教えないでください。
3

順位を確認する

ログインすると、キーワードごとの検索順位が一覧で表示されます。

キーワード 今週 先週 変化
転職 エージェント おすすめ 8位 12位 ▲ 4
30代 転職 平均年収 15位 13位 ▼ 2
退職理由 ポジティブ 言い換え 5位 5位 — 0

※ イメージです。実際の数値とは異なります

💡 1位〜10位 に入るとGoogleの1ページ目に表示されます。▲（上がった） は良いサイン、▼（下がった） はリライトのサインです。

記事を修正する（リライト）

順位が落ちた記事を自動で改善する方法

1

Claudeに「リライトして」と伝える

リライトして

特定の記事を直したい場合：

「転職 退職理由」の記事をリライトして
2

完了を待つ（約5〜10分）

Claudeが記事を分析して、自動で改善してくれます。終わったら改善内容を教えてくれます。

✅ 順位が落ちてきたと思ったら、すぐリライトを依頼しましょう。だいたい1〜2週間で効果が出ます。

よくある質問

困ったときはここを見てください

Claudeに話しかけても動かない
▼
SEOフォルダ（IBT-SEO-Team）が正しく開けているか確認してください。フォルダが違う場所で開いていると、Claudeは動きません。しゅうさんに「SEOフォルダを開いて」と伝えてください。
記事投稿が「エラー」で止まった
▼
もう一度「記事を投稿して」と伝えてみてください。それでもダメな場合は、エラーメッセージをスクリーンショットしてしゅうさんに送ってください。
KeywordMapにログインできない
▼
パスワードは Otokake0715!（最後に「!」がついています）。コピー&ペーストで試してみてください。それでもダメな場合はしゅうさんに連絡してください。
記事投稿は1日何本まで？
▼
基本は 1〜2本/日 です。Google Sheetsに「投稿予定」として登録されているキーワードから順番に投稿されます。キーワードがなくなると投稿されません。
投稿した記事はどこで確認できる？
▼
投稿完了メッセージに URL（https://ib-tec.co.jp/...） が表示されます。そのURLをクリックすれば記事を確認できます。WordPress管理画面（ib-tec.co.jp/wp-admin）でも一覧で確認できます。

困ったらしゅうさんに聞いてください
